Genera una función recursiva en Python que resuelva las siguientes series:
Fibonacci : Donde el parámetro de entrada será el limite de los elementos a buscar. Ejemplo: Fibonacci(5) -> [1,1,2,3,5,8] 
Factorial:  Donde el parámetro de entrada será la base para el factorial. Ejemplo: Factorial(7) -> (5040, [7,6,5,4,3,2,1])
